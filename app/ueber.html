Über Bitweg

Bitweg ist eine kostenlose Lern-App für Python und C++. Sie funktioniert wie eine Sprachlern-App: kurze Lektionen, sofortiges Feedback, XP, Tages-Serien und Abzeichen. Der Code läuft echt im Browser, ohne Installation und ohne Konto.

Bitweg (mit e) ist ein Lernprojekt fürs Programmieren und hat nichts mit der Musiksoftware Bitwig zu tun.

Wie eine Lektion funktioniert

  • Erklärkarten mit Beispielcode und Ausgabe
  • Multiple Choice, Ausgabe vorhersagen, Lückentext und Zeilen ordnen
  • Code reparieren und selbst schreiben: Der Code wird echt ausgeführt und mit der erwarteten Ausgabe verglichen. Typische Fehlermeldungen übersetzt Bitweg in verständliche Hinweise.
  • Dazu: Training mit immer neuen, zufällig erzeugten Aufgaben, Abschnittstests, Gold-Lektionen, Projekte mit mehreren Etappen, freie Aufgaben und ein Labor für eigene Programme.

Für Lehrkräfte und den Informatikunterricht

  • Keine Installation: Ein aktueller Browser reicht (Chrome, Edge, Firefox, Safari), auch auf Tablets. Python läuft direkt im Browser. Beim ersten Ausführen werden einmalig etwa 10 MB geladen.
  • Ohne Konto nutzbar: Dann bleibt der Fortschritt nur im Browser des Geräts. Auf geteilten Schul-PCs empfiehlt sich deshalb ein Konto, damit der Stand nicht verloren geht oder bei anderen landet.
  • Mit Konto: Fortschritt auf allen Geräten. Schüler können sich gegenseitig als Freunde hinzufügen, sehen dann Kurs und Fortschritt der anderen und eine Wochen-Rangliste.
  • Klassen-Gruppe: Eine Gruppe mit Chat, Bildern und Dateien für bis zu 60 Mitglieder. Hinzufügen kann man nur eigene Freunde. Wer die Gruppe gründet, kann Admins ernennen und Mitglieder entfernen.
  • Moderation: Nachrichten können gemeldet, Nutzer blockiert werden. Eigene Nachrichten lassen sich löschen.
  • Echtes C++: Im Browser prüft Bitweg C++-Aufgaben nur nach Regeln. Für echtes Kompilieren gibt es eine Version für den eigenen PC (start.bat, mit g++ oder Visual Studio). Die Anleitung steht in der App unter „Werkstatt“.
  • Oberfläche auf Deutsch und Englisch.

Datenschutz

Keine Werbung, keine Cookies, kein Tracking. Ohne Konto werden keine Lerndaten an einen Server geschickt. Konten liegen bei Supabase in Frankfurt. Details stehen in der Datenschutzerklärung.

Technik

Bitweg ist eine statische Web-App aus HTML, CSS und JavaScript-Modulen, ohne Build-Schritt, gehostet über GitHub Pages. Die Oberfläche baut JavaScript im Browser auf. Lektionen und Aufgaben liegen als JavaScript-Dateien im Quellcode. Konten, Freunde und Chat laufen über Supabase (PostgreSQL); wer was lesen und schreiben darf, prüft die Datenbank selbst per Row Level Security. Python läuft über Pyodide (WebAssembly). Der Quellcode ist offen: github.com/VRTomsky/Bitweg.
